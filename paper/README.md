# 论文数据包（paper/）

本目录随论文提交，存放正文图表所依据的导出数据与说明。

## 训练统计导出（训练统计导出/）

| 文件 | 内容 | 对应正文 |
|---|---|---|
| `stats_report.txt` | 训练日志复算报告：会话切分、损失分箱、对局长度统计、参数量核对 | 图 3、表 7、§3.2 |
| `stats_detail.json` | 上述复算的机器可读明细（逐点、逐箱、逐会话） | 图 3、表 7 |
| `fig1_compare.csv` | 图 3 的 11 个坐标点与复算值对照 | 图 3 |
| `moves_distribution.csv` | 对局长度直方图计数（早期/后期两个窗口） | 表 7 |

## 反馈编码（反馈编码/）

表 8 的 6 个反馈案例的匿名化编码（C01—C06），含平台、评论 ID、类别、现象与修复版本；评论链接可由“来源 + 评论 ID”打开。编码为作者单人完成，未做双人复核，只作改进线索。
